# chip-ref-lm358：反相放大器非理想特性仿真

**对应教程**：https://geek-doc.cn/chip-design/chip-ref/lm358.html（上线后生效）

## 复现方式

```bash
node inverting-sim.js        # 无需任何依赖，Node 18+ 直接跑
```

## 说明

含真实非理想项的反相组态模型：开环增益 100dB、失调电压 2mV、单 5V 电源摆幅窗 [5mV, VCC−1.5V]（均取自 datasheet 典型值）。三部分：增益误差表（1/10/100 倍）、摆幅削顶扫描（G=−10）、失调占比（G=−100，1/10/50mV 信号）。`results.txt` 是真实运行输出。

## 关键结论

- 增益精度优秀：100 倍闭环误差仅 -0.10%。
- **摆幅硬伤**：5V 单电源输出 3.5V 削顶（高侧差 1.5V 到不了轨）。
- **失调致命**：G=100 时失调贡献恒 202mV，对 1mV 信号占比 202%——小信号场景必须换精密运放或校零。
