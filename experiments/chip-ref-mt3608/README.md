# chip-ref-mt3608：MT3608 升压模块 3.7V→5V 纹波、负载步进与开关电流裕量实测

**对应教程**：<https://geek-doc.cn/chip-design/chip-ref/mt3608.html>

## 复现方式

需要 LTspice（本实验用 26.1.1 for Windows）：

```powershell
.\run.bat
```

或分别执行：

```powershell
LTspice.exe -b mt3608_ripple.cir
LTspice.exe -b mt3608_load_step.cir
```

批处理跑完生成同名 `.log`（.meas 实测值）与 `.raw`（波形）。仓库内 `ripple-steady.log`、`load-step.log` 是本次实测的原始输出。

## 实验设计

开环固定占空比的开关级升压行为宏模型，按 MT3608 迷你模块常用参数取值：1.2MHz 开关频率、电感 4.7µH、输出电容 22µF（10mΩ ESR）、肖特基整流管 Vf≈0.4V、开关管 Ron 10mΩ。占空比按含整流管压降的伏秒平衡反推 `D=1−Vin/(Vout+Vd)=0.315`，PWM 边沿 1ns。宏模型不含反馈与限流跳闸，只测被动稳态：

- `mt3608_ripple.cir`：3.7V 锂电输入升压到 5V、0.5A 负载，测稳态输出、峰峰纹波、电感电流峰谷与输入平均电流。
- `mt3608_load_step.cir`：负载 20/10/6.67/5Ω 四档步进（输出电流约 0.25–1A），逐档测输出与电感峰值。CCM 升压拓扑里开关导通期电感电流全部流过开关，峰值开关电流与电感峰值等量，直接用 `MAX I(L1)` 与 datasheet 2A 开关电流限值做设计核对。

## 关键结论（本次实测）

- 0.5A 工况稳态输出 **4.971V**；电感均值 **0.724A**，是输出电流的 1.45 倍，与升压电流关系 `IL=Iout/(1−D)=1.46·Iout` 吻合；电感峰峰纹波 0.205A，与解析式 `ΔIL=Vin·D/(L·f)=0.215A` 同量级。
- 四档负载输出 4.95–4.98V，电感均值随负载线性上移；最重档（约 1A 输出）电感峰值 **1.545A**，距 2A 开关电流限值只剩约 0.45A 裕量——升压模块的「2A」约束的是开关电流，折算到输出端连续可用电流约 1.3A，不能按 2A 负载理解。
- 输出纹波随负载减轻反而变大（1A 档 6.2mV、0.25A 档 25.1mV）：轻载下高 Q 的 LC 滤波阻尼不足，开关边沿激励的振铃占了峰峰值主体；选型时轻载纹波要单独验证，不能只看额定负载数据。
- 输入平均电流与电感均值相等（0.724A），升压变换的输入电流是连续三角波而非脉冲，这与 buck 侧从电源抽取脉冲电流形成对照，决定了两类模块输入端电容配置的差异。
