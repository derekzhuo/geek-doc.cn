# Changelog

## 0.3.0

- 新增 D009 配套脚本 `gray_reflection.py`：格雷码反射构造（镜像复制 + 正序补 0 / 镜像补 1）、相邻码字（含首尾循环）汉明距离恒为 1 的断言、反射构造与异或公式 `g = b ^ (b>>1)` 的等价性验证，以及 n=3/4 下普通二进制与格雷码的翻转位数对照。
- `tests/test_check.py` 追加反射构造前三层手算结果、n=1..8 距离与等价性断言、翻转统计用例，自校验变为 8 项。
- 一键运行脚本 `run.sh` / `run.ps1` 纳入新演示，README 与 START-HERE 同步脚本对照、运行示例与目录结构。

## 0.2.0

- 新增 D008 配套脚本 `bcd_decimal.py`：8421-BCD 编码与解码（拒绝 1010~1111 非法码组）、单十进制位 +6 校正（覆盖 10~15 区间修正与二进制进位修正两个分支）、多位数逐位进位传播。
- `tests/test_check.py` 追加 BCD 编码、非法码组、两类修正分支与进位传播用例，自校验变为 7 项。
- 一键运行脚本 `run.sh` / `run.ps1` 纳入新演示，README 同步脚本对照与目录结构。

## 0.1.0

- 建立数字 IC 入门 P01 阶段（数制、编码与逻辑代数）实验包，覆盖 D001–D007 七篇教程。
- 六个零第三方依赖脚本：阈值判决、进制转换、逐位加法、三码对照与补码减法、符号扩展、进位与溢出对照。
- 每个脚本无参运行即输出内置算例的完整推导，并支持命令行传参自行试验。
- 加入纯标准库自校验 `tests/test_check.py`，以及 Bash / PowerShell 一键运行脚本。
- 加入中文 README 与 START-HERE 快速上手文档。
