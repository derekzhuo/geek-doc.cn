# chip-ref-lm393：LM393 开漏比较器阈值翻转、上拉电阻选型与窗口检测实测

**对应教程**：<https://geek-doc.cn/chip-design/chip-ref/lm393.html>

## 复现方式

需要 LTspice（本实验用 26.1.1 for Windows）：

```powershell
.\run.bat
```

或分别执行：

```powershell
LTspice.exe -b lm393_threshold.cir
LTspice.exe -b lm393_window.cir
```

批处理跑完生成同名 `.log`（.meas 实测值）与 `.raw`（波形）。仓库内 `threshold-sweep.log`、`window-detect.log` 是本次实测的原始输出。

## 实验设计

LM393 是双通道开漏输出比较器，行为宏模型用压控开关模拟开漏级（Ron=20Ω、Roff=10MΩ、1mV 迟滞），输出级必须外接上拉电阻才能输出高电平：

- `lm393_threshold.cir`：同相端接 2.5V 基准、反相端接 0–5V 扫描输入，上拉电阻按 10k/4.7k/1k 三档步进。测翻转阈值（输出跨过 2.5V 的输入点）、输入 0.5V 时的输出低电平与灌电流、输入 4.5V 时的输出高电平，直接回答「上拉电阻怎么选」。
- `lm393_window.cir`：两个比较器构成窗口检测——下限比较器在输入低于 1.7V 时拉低、上限比较器在输入高于 3.3V 时拉低，两个开漏输出线与共用一个 10k 上拉。测窗口上下沿与窗内/窗外电平，验证开漏级天然支持线与。

## 关键结论（本次实测）

- 三档上拉电阻下翻转阈值都是 **2.505V**（基准 2.5V，偏差来自 0.01V 扫描步长与 1mV 模型迟滞），阈值本身与上拉取值无关；上拉电阻改变的是输出级的电流量级，不是比较点。
- 输出低电平随灌电流同步抬高：10kΩ 上拉、灌电流 0.499mA 时 VOL=9.98mV；4.7kΩ、1.06mA 时 VOL=21.2mV；1kΩ、4.90mA 时 VOL=98.0mV——正好对应 20Ω 开漏导通电阻的分压。上拉越小低电平越差，数字电路的低电平输入裕量要按最重档核算，不能只看上拉能力。
- 输出高电平三档都接近 5V（4.995–5.000V），漏电流只在 Roff=10MΩ 上产生毫伏级压降；高电平裕量不是开漏级的约束项，上升速度才是（本直流实验不覆盖）。
- 窗口检测的两个交叉点实测 **1.705V 与 3.305V**，与设计边界 1.7V/3.3V 一致；窗内 2.5V 处输出 4.990V 高电平，窗外两侧都是 9.98mV 低电平。两个开漏输出直接短接即实现线与，不需要额外逻辑门，这是开漏级相对推挽输出最关键的用法。
