# Lab 03：「1101」序列检测器（状态机）

**对应教程**：https://geek-doc.cn/chip-design/beginner/seed-verilog-rtl-starter-lab.html

## 这个实验解决什么问题

通信协议解析、按键指令识别、比特流同步都需要在连续输入里识别特定模式。这类问题的标准解法是有限状态机（FSM）：每个状态记录「目前已经匹配到目标模式的多长前缀」，每来一个比特就按前缀关系跳转。

## 模块接口

```verilog
seq_detector_mealy (
  input  wire clk,
  input  wire rst_n,
  input  wire din,    // 每个时钟输入 1 比特
  output reg  found   // 识别到 1101 后拉高一个时钟周期
);
```

## 状态编码

状态只保存「当前流的最长后缀中，属于目标模式前缀的那一段」：

| 状态 | 已匹配前缀 | din=0 跳转 | din=1 跳转 |
|---|---|---|---|
| S0 | 空 | S0 | S1 |
| S1 | `1` | S0 | S2 |
| S2 | `11` | S3 | S2 |
| S3 | `110` | S0 | S1，同时 `found=1` |

### 重叠匹配的关键

在 S3 收到 1 命中模式后，下一个状态回到 S1 而不是 S0，因为最后这个比特 `1` 本身又是新模式的前缀。所以输入 `1101101` 会命中两次，testbench 专门验证了这一点。

### Mealy 与 Moore 的差别

- Mealy：输出由「当前状态 + 当前输入」共同决定，输入满足条件的当拍就能给出结果，延迟小，但组合输出容易带毛刺。
- Moore：输出只由状态决定，通常要多等一个时钟。

本实验保留 Mealy 的跳转逻辑，但把 `found` 放到时钟进程里寄存输出，既保留当拍判定的语义，又得到一个干净、无组合毛刺的整周期脉冲，方便下游直接当使能用。

## 怎么跑

```bash
make lab03-seq-detector-fsm
```

三组用例：普通命中一次、重叠流 `1101101` 命中两次、近似流 `1100` 零命中，全部 PASS 才算通过。

## 波形怎么读

```bash
gtkwave lab03-seq-detector-fsm/sim_build/lab03.vcd
```

| 信号 | 观察点 |
|---|---|
| `din` | 每个时钟一位的串行输入 |
| `dut.state` | 按 S0→S1→S2→S3 推进，失配时回退 |
| `found` | 每次命中后出现一个时钟宽的脉冲，重叠流里出现两次 |

testbench 在时钟下降沿驱动 `din`，保证 DUT 上升沿采样时输入已经稳定；`found` 在下降沿采样计数，避开同一沿上的寄存器更新竞争。
