# chip-ref-mp1584：MP1584 高频降压纹波与 150k/1.5MHz 频率对照实测

**对应教程**：<https://geek-doc.cn/chip-design/chip-ref/mp1584.html>

## 复现方式

需要 LTspice（本实验用 26.1.1 for Windows）：

```powershell
.\run.bat
```

或分别执行：

```powershell
LTspice.exe -b mp1584_ripple.cir
LTspice.exe -b mp1584_freq_compare.cir
```

批处理跑完生成同名 `.log`（.meas 实测值）与 `.raw`（波形）。仓库内 `ripple-steady.log`、`freq-compare.log` 是本次实测的原始输出。

## 实验设计

开环固定占空比的开关级行为宏模型，按 MP1584 迷你模块常用参数取值：最高 1.5MHz 开关频率、电感 22µH、陶瓷输出电容 44µF（约 5mΩ ESR）、肖特基续流二极管 Vf≈0.5V、开关管 Ron 10mΩ。占空比按含续流压降的伏秒平衡取 `D=(Vout+Vd)/(Vin+Vd)=0.44`，PWM 边沿 1ns。宏模型不含反馈与限流跳闸，只测被动稳态：

- `mp1584_ripple.cir`：12V→5V、1A 负载，测稳态输出、峰峰纹波、电感电流峰谷、输入平均电流与开关节点摆幅。
- `mp1584_freq_compare.cir`：同一宏模型把开关频率在 150kHz（LM2596 一档）与 1.5MHz（MP1584 一档）之间步进，L/C 保持不变，直接量频率对电感纹波电流与输出纹波的影响。

## 关键结论（本次实测）

- 1.5MHz、1A 工况稳态输出 **4.964V**，电感电流在 0.93–1.05A 之间波动，峰峰 0.116A，与解析式 `ΔIL=(Vin−Vout)·D/(L·f)=0.093A` 同量级，全程 CCM；开关节点 −0.52V 到 11.99V 摆动。
- 频率对照（同一网表、同一测量窗口，配对比较）：150kHz 档电感电流峰峰 **0.935A**、输出纹波 **18.5mV**，1.5MHz 档分别降到 **0.097A** 与 **3.62mV**——10 倍频率换来约 10 倍纹波电流收敛、约 5 倍输出纹波改善。150kHz 档电感谷值 0.53A，已在 1A 负载的 CCM 边界附近，这就是 LM2596 类模块必须用百微亨级大电感的原因。
- 陶瓷电容 ESR 极低，输出纹波的主体不再是三角波的 ESR 分量，而是开关边沿激励 LC 谐振留下的欠阻尼振铃；不同测量窗口统计到的峰峰值会有差异（1.5MHz 档另一窗口为 14.9mV），频率对照结论以同一网表配对数据为准。低 ESR 是把双刃剑：纹波小了，但反馈环路补偿必须跟上，否则振铃难消。
- 能量账：1A 档输入 5.22W、输出 4.93W，宏模型效率约 94%，损耗主要仍是续流二极管；这也是新一代同步整流模块把二极管换成 MOS 管的动因。
