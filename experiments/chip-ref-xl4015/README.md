# chip-ref-xl4015：XL4015 降压模块 CCM 纹波、负载步进与限流裕量实测

**对应教程**：<https://geek-doc.cn/chip-design/chip-ref/xl4015.html>

## 复现方式

需要 LTspice（本实验用 26.1.1 for Windows）：

```powershell
.\run.bat
```

或分别执行：

```powershell
LTspice.exe -b xl4015_ripple.cir
LTspice.exe -b xl4015_load_step.cir
```

批处理跑完生成同名 `.log`（.meas 实测值）与 `.raw`（波形）。仓库内 `ripple-steady.log`、`load-step.log` 是本次实测的原始输出。

## 实验设计

开环固定占空比的开关级行为宏模型，按 XL4015 模块常用参数取值：180kHz 开关频率、模块板级电感 100µH、输出电容 220µF（20mΩ ESR）、SS54 类肖特基续流二极管（Vf≈0.5V）、开关管 Ron 10mΩ。占空比按含续流压降的伏秒平衡反推 `D=(Vout+Vd)/(Vin+Vd)=0.442`，PWM 边沿取 1ns 避免边沿时间侵蚀有效占空比。宏模型不含反馈环路与限流跳闸，只测量被动稳态行为，限流规格以设计核对方式表达：

- `xl4015_ripple.cir`：12V 输入、2.5Ω 负载（约 2A），测稳态输出均值与峰峰纹波、电感电流均值/峰谷、输入平均电流、开关节点摆幅。
- `xl4015_load_step.cir`：负载电阻 10/5/2.5/1.67/1Ω 五档步进（输出电流约 0.5–4.94A），逐档测同样的量，最高档把峰值开关电流与 datasheet 5A 周期限流规格线对照。

## 关键结论（本次实测）

- 2A 工况稳态输出 **4.9897V**（偏差约 10mV），峰峰纹波 **4.14mV**；电感电流在 1.91–2.08A 之间三角波动，纹波峰峰 0.172A，与解析式 `ΔIL=(Vin−Vout)·D/(L·f)=0.178A` 吻合，全程 CCM。
- 开关节点在 **−0.54V 到 11.98V** 之间摆动：负摆幅是续流二极管钳位，不是振荡——选型时 MOS 管耐压按输入电压而不是按输出电压留余量。
- 五档负载输出区间 4.94–5.015V，开环负载调整率约 75mV；电感纹波峰峰恒定 0.172A（与负载无关，由 Vin、L、f 决定），均值随负载线性移动。
- 限流裕量核对：4.94A 负载档峰值开关电流 **5.027A**，已越过 5A 周期限流规格线，真实模块在该工况会进入限流；按纹波一半折算，连续输出的实际天花板约 4.8A，模块标称「5A」是限流点不是可持续工作点。
- 轻载（0.5A）输出纹波反而最大（**29.9mV**）：轻载下 LC 输出滤波阻尼不足、Q 值升高，开关边沿激励的振铃衰减慢；闭环反馈模块会抑制这一成分，开环宏模型把它如实暴露出来。
- 能量账：2A 档输入功率 10.58W、输出 9.96W，宏模型效率约 94%，损耗几乎全部来自续流二极管（占空比外 56% 时间导通）；同步整流模块换 MOS 管续流正是冲这个损耗点来的。
