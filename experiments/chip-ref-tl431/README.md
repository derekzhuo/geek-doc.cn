# chip-ref-tl431：TL431 并联稳压器 1mA 工作电流边界与可调分压负载能力实测

**对应教程**：<https://geek-doc.cn/chip-design/chip-ref/tl431.html>

## 复现方式

需要 LTspice（本实验用 26.1.1 for Windows）：

```powershell
.\run.bat
```

或分别执行：

```powershell
LTspice.exe -b tl431_operating_range.cir
LTspice.exe -b tl431_adjustable.cir
```

批处理跑完生成同名 `.log`（.meas 实测值）与 `.raw`（波形）。仓库内 `operating-range.log`、`adjustable-load.log` 是本次实测的原始输出。

## 实验设计

TL431 是并联型可调精密稳压器，行为模型用顶层 B 源电流沉实现：跨导 1000A/V、以 2.495V 内部基准为调节目标，阴极电流钳在 [0, 100mA]（datasheet 阴极电流窗口）。1mA 最小工作电流不靠硬编码，而是由外电路（限流电阻与负载）的电流分配自然涌现——电流沉算到负值时钳到 0，稳压随即丧失：

- `tl431_operating_range.cir`：REF 接阴极的固定 2.5V 模式，1kΩ 限流电阻，电源 0–24V 扫描。由于跨导很大，一旦进入调节区阴极电压就被钳在 2.495V 附近毫伏级，因此工作区下边界用「阴极电流达到 1mA 时的电源电压」刻画（`WHEN I(B1)=0.001`），而不是找电压交叉点；另取 5/12/24V 三点核对稳压值与电流解析式 `Ik=(Vsup−Vka)/Rlim`。
- `tl431_adjustable.cir`：10k/10k 分压把输出编程到 4.99V，12V 电源经 470Ω 限流（总电流预算约 14.9mA），负载电阻 10k/2k/1k/500/330/250Ω 六档步进，逐档测输出电压、REF 电压、阴极分流电流与负载电流，观察分流电流被挤到 0 后稳压崩溃的边界。

## 关键结论（本次实测）

- 固定模式下阴极电流达到 1mA 的电源边界实测 **3.495V**，与解析式 `Vsup=Vka+Imin·Rlim=2.495+1=3.495V` 精确一致；5/12/24V 三点稳压值 2.4950/2.4950/2.4950V，阴极电流 2.505/9.505/21.505mA 与解析值逐项吻合。限流电阻选型必须保证最低电源电压下仍有 ≥1mA 余量，否则 TL431 根本不进入调节区。
- 可调模式前四档（负载 10k–500Ω，负载电流 0.5–10mA）输出稳定在 **4.9900V**、REF 保持 2.4950V，阴极分流电流从 14.17mA 逐档降到 4.69mA；330Ω 档分流电流被挤到 **0**，输出跌到 4.902V，250Ω 档进一步跌到 4.133V——总电流预算 14.9mA 被负载和分压网络吃干后，并联调节器没有任何剩余调节能力，这是 TL431 与串联 LDO 最不同的失效方式：负载越重越先饿死的是稳压器自己。
- 工程算法：先按 `(Vsup_min−Vka)/Rlim` 算总电流预算，再减去分压网络电流（本实验 0.25mA）和最大负载电流，剩下的才是 TL431 的分流余量；1mA 是下限，100mA 是上限，设计点通常留在几毫安到几十毫安之间。
