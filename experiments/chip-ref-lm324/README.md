# chip-ref-lm324：LM324 四通道失调预算与单电源轨到轨摆幅实测

**对应教程**：<https://geek-doc.cn/chip-design/chip-ref/lm324.html>

## 复现方式

需要 LTspice（本实验用 26.1.1 for Windows）：

```powershell
.\run.bat
```

或分别执行：

```powershell
LTspice.exe -b lm324_four_channel.cir
LTspice.exe -b lm324_rail_swing.cir
```

批处理跑完生成同名 `.log`（.meas 实测值）与 `.raw`（波形）。仓库内 `four-channel-offset.log`、`rail-swing.log` 是本次实测的原始输出。日志里出现的 `Gmin stepping succeeded` 是 LTspice 求解器对含理想行为源电路的常规收敛辅助，不影响结果。

## 实验设计

LM324 是四通道单电源运放，行为宏模型取开环增益 100kV/V、输出钳位在 `[0.02V, Vcc−1.5V]`（对应单电源下低至地、高侧距正电源 1.5V 的摆幅特征）、开环输出电阻 100Ω。失调电压用四个确定性取值（−7/−2/+2/+7mV，均在 datasheet 7mV 限值内）分别注入四个通道，验证输出误差预算的换算关系；这是确定性预算核对，不模拟真实器件的随机分布：

- `lm324_four_channel.cir`：四个通道接成增益 11 的同相放大器（RFG=1k、RFF=10k），共模输入 0.3V，测各通道输出，看输入失调被闭环增益放大后的通道间离散。
- `lm324_rail_swing.cir`：单通道增益 11，输入从 0 扫到 0.5V（理想输出覆盖 0–5.5V），测低端输出、线性区输出、高端饱和输出与饱和拐点，直接呈现单电源运放的输出摆幅边界。

## 关键结论（本次实测）

- 四通道在 0.3V 输入下实测输出 **3.223/3.278/3.322/3.377V**：理想值 3.3V，偏差 −77/−22/+22/+77mV，正好等于 11 倍闭环增益乘以各自输入失调（−7/−2/+2/+7mV），偏差在亚毫伏级。通道间总离散 0.154V——多通道同步采样应用里，失调误差必须按闭环增益放大后核算，不能只看输入端的 7mV。
- 轨摆幅扫描：输入 1mV 时输出 33mV（=11×3mV，仍在线性区，体现输入可低至地附近）；输入 0.2V 时输出 2.222V 与线性公式一致；输入 0.5V 时理想输出 5.52V 被钳在 **3.468V**，饱和拐点（输出 3.45V）出现在输入 **0.3125V**。5V 供电下高侧可用输出实际只到约 3.5V，直接驱动 5V 满幅 ADC 会削顶，这是 LM324 单电源应用最常见的踩坑点。
- 低端钳位 20mV 的宏模型设定在本实验线性区未被触发，但轨摆幅网表保留该边界，可在输入接地时复测；真实 LM324 低侧可到几十毫伏甚至地电位，高侧 1.5V 余量才是更硬的约束。
