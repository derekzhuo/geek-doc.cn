# chip-ref-atmega328p：UBRR 波特率误差实算

**对应教程**：https://geek-doc.cn/chip-design/chip-ref/atmega328p.html（上线后生效）

## 复现方式

```bash
node baud-error.js        # 无需任何依赖，Node 18+ 直接跑
```

## 说明

按 ATmega328P datasheet §24.3 的 UBRR 取整规则（无小数分频器），对 1200–460800 共 8 档标准波特率分别计算 U2X=0（16 分频）与 U2X=1（8 分频）两种模式的实际波特率与误差，每档枚举 floor/ceil 两种取整并取误差更小者。`results.txt` 是真实运行输出。

## 关键结论

- 9600–38400 两种模式误差仅 0.16%；**从 57600 档开始 U2X=0 已出 ±2% 红线（+2.12%）**。
- **115200 必须开 U2X**：-3.55% → +2.12%（红线边缘，工程可用）。
- ≥230400 两模式全灭（±3.5%~+8.5%），16MHz 晶振的经典 AVR 天花板就在 115200。
