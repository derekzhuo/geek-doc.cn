# chip-ref-uln2003：ULN2003 达林顿驱动阵列输入阈值、阻性 Vce(sat) 与感性续流实测

**对应教程**：<https://geek-doc.cn/chip-design/chip-ref/uln2003.html>

## 复现方式

需要 LTspice（本实验用 26.1.1 for Windows）：

```powershell
.\run.bat
```

或分别执行：

```powershell
LTspice.exe -b uln2003_threshold.cir
LTspice.exe -b uln2003_resistive.cir
LTspice.exe -b uln2003_inductive.cir
```

批处理跑完生成同名 `.log`（.meas 实测值）与 `.raw`（波形）。仓库内 `threshold-sweep.log`、`resistive-saturation.log`、`inductive-flyback.log` 是本次实测的原始输出。

## 实验设计

ULN2003 是七路 NPN 达林顿灌电流驱动阵列，每路带一个阴极共接 COM 的续流二极管。行为模型用 LTspice 压控开关表达达林顿输出（Ron=10Ω、Roff=10MΩ），续流二极管用 `D(Ron=0.1 Vfwd=0.7)`，输入导通阈值按两个发射结压降取 1.4V。三个网表各自只回答一个问题：

- `uln2003_threshold.cir`：5V 供电、1kΩ 固定上拉负载，输入 0–5V 扫描。差分控制端接成「输入对 1.4V 基准」，输入高于基准时开关灌通、输出拉低，与真实器件极性一致；测输出越过 2.5V 的输入阈值，以及输入 5V 全开时的输出低电平。
- `uln2003_resistive.cir`：输入固定 5V 全开，负载 1k/470/220/100/50Ω 五档步进，逐档测 Vce(sat) 与灌电流。这个网表故意不放续流二极管——真实低边阻性台里 COM 接电源轨，输出为低时二极管反偏不参与；续流行为交给第三个网表单独覆盖，避免接地二极管在重负载档正偏抢流污染数据。
- `uln2003_inductive.cir`：12V 继电器线圈模型（10mH 串联 47Ω），输入 5ms 导通后关断，续流二极管阴极经 COM 回到 12V 轨。测关断瞬间的输出钳位峰值、线圈稳态电流，以及关断后 0.5ms/1ms 的衰减尾。

## 关键结论（本次实测）

- **输入阈值 1.405V**，与两个 Vbe 串联的 1.4V 设计基准只差 5mV（扫描步长 10mV 加 1mV 开关迟滞）；输入 5V 全开时输出低电平 0.0495V，恰好等于 1kΩ 负载档灌电流在 10Ω 导通电阻上的压降，阈值网表与阻性网表在同一工作点互证。
- **阻性五档 Vce(sat) 严格随灌电流线性增长**：4.95/10.42/21.74/45.45/83.33mA 对应 0.0495/0.1042/0.2174/0.4545/0.8333V，逐档满足 Vce(sat)=Ic×10Ω。达林顿输出的低电平不是接近 0 的轨电压，灌电流越大压降越高——83mA 时已到 0.83V，选型时必须按目标电流查 datasheet 的 Vce(sat) 曲线而不是只看「逻辑低」。
- **感性关断尖峰被续流二极管钳在 Vcc+Vf**：实测峰值 12.7211V，等于 12V 电源加 0.721V 管压降（0.7V 正向压降 + 0.1Ω 导通电阻×0.2105A，逐项对得上）；线圈稳态电流 0.2105A 与 `12V/(47Ω+10Ω)` 的解析值一致。关断后 0.5ms 电流衰减到 6.53mA、1ms 到 1.2µA，呈指数衰减尾；分段二极管模型的等效电阻随电流变化，衰减比单一 L/R 理想指数更快，工程上用 L/R 做保守估算即可。
- 行为级模型的边界：开关 Ron 是定值，复现的是 Vce(sat) 随电流近似线性的宏观趋势，不包含真实达林顿管的温度系数与大电流弯曲；二极管只刻画正向钳位，不建反向恢复。定量设计仍以 datasheet 曲线为准。
