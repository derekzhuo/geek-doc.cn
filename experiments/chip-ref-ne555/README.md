# chip-ref-ne555：NE555 非稳态振荡仿真

**对应教程**：https://geek-doc.cn/chip-design/chip-ref/ne555.html（上线后生效）

## 复现方式

```bash
node astable-sim.js        # 无需任何依赖，Node 18+ 直接跑
```

## 说明

用 RC 充电解析解逐事件推进电容电压（充电经 R1+R2、放电经 R2），在 1/3 与 2/3 VCC 阈值间翻转，测频率与占空比，与经典公式 f=1.44/((R1+2R2)·C) 逐组对照；另演示 R1→0 的占空比极限。`results.txt` 是真实运行输出。

## 关键结论

- 三组 RC 仿真 vs 公式偏差恒为 **+0.19%**——根源是 1.44 常数对 1/ln2=1.4427 的舍入，公式精度上限就是 ±0.2% 量级。
- 占空比公式精确成立；标准接法占空比恒 >50%（R1=100Ω 极限组 50.25%），要 50% 以下必须改电路。
