# chip-ref-lm317：LM317 可调稳压器分压步进与最小负载设计核对

**对应教程**：<https://geek-doc.cn/chip-design/chip-ref/lm317.html>

## 复现方式

需要 LTspice（本实验用 26.1.1 for Windows）：

```powershell
.\run.bat
```

或分别执行：

```powershell
LTspice.exe -b lm317_output_step.cir
LTspice.exe -b lm317_minload.cir
```

批处理跑完生成同名 `.log`（.meas 实测值）与 `.raw`（波形）。仓库内 `r2-step.log`、`minload-check.log` 是本次实测的原始输出。

## 实验设计

行为级宏模型按 LM317 datasheet 取 OUT-ADJ 基准 1.25V、dropout 电压 1.5V、调整管串联电阻 25mΩ、ADJ 引脚电流 50µA（电流流出 ADJ 注入分压节点）；B 源跨在输入与内部节点之间，负载电流真实取自电源：

- `lm317_output_step.cir`：24V 输入、R1 固定 240Ω，R2 按 1/390/720/1200/2000/2880Ω 六档步进（1Ω 档近似 R2 短路，即输出等于基准的边界；LTspice 不允许电阻实例取 0Ω），测每档输出电压、OUT-ADJ 基准差与 R1 编程电流。
- `lm317_minload.cir`：同样瞄准 5V 输出的两种分压方案——A 案 R1=240/R2=720Ω（编程电流 1.25/240≈5.21mA），B 案 R1=1000/R2=3000Ω（仅 1.25mA），量编程电流相对 datasheet 5mA 最小负载规格线的裕量。理想宏模型两案都会稳压，5mA 以下真实器件的失稳压曲线 datasheet 不提供，结论以设计核对方式表达，不构造失效数据。

## 关键结论（本次实测）

- 六档输出 **1.2551 / 3.3004 / 5.0355 / 7.5592 / 11.7655 / 16.3923V**，与公式 `Vout = 1.25×(1+R2/R1) + Iadj×R2` 逐项偏差不超过 2mV；ADJ 电流项在 R2=2880Ω 档贡献约 0.144V，高输出档不能省略。
- 全档基准差稳定在 **1.24987V**（5.21mA 编程电流在 25mΩ 串联电阻上约 0.13mV 压降），编程电流恒定 **5.208mA**，与 `1.25V/240Ω` 的设计值一致——这正是 datasheet 推荐 R1=240Ω 的原因：仅靠 R1 就满足 5mA 最小负载。
- 最小负载核对：A 案编程电流 5.208mA、裕量 **+0.208mA**，满足规格；B 案只有 1.250mA、裕量 **−3.750mA**，不外接泄放负载时真实器件可能退出稳压。同是 4 倍分压比，R1 取值决定设计是否成立。
- A 案在 24V 输入下输出跌破基准 1%（1.2375V）对应的输入电压为 **6.486V**，等效 dropout 压差约 1.45V，与 1.5V 模型参数吻合；5V 输出应用至少留 7V 以上输入。
