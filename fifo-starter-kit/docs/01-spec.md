# 同步 FIFO 接口与时序规格

## 1. 功能范围

本模块是单时钟、同步读写 FIFO。写方和读方共用 `clk`，数据按照先进先出顺序传输。模块只实现功能级行为，不包含跨时钟域同步、门级时序或形式验证。

## 2. 参数

| 参数 | 约束 | 说明 |
|---|---|---|
| `DW` | 大于 0 | 每项数据的位宽 |
| `AW` | 大于等于 1 | 地址位宽，深度 `DEPTH = 2**AW` |
| `ALMOST` | `0 <= ALMOST < DEPTH` | 将满、将空的水位阈值 |

参数合法性由实例化方保证。V0.1 未加入参数断言。

## 3. 接口

| 信号 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| `clk` | 输入 | 1 | 读写共用时钟 |
| `rst_n` | 输入 | 1 | 低有效异步复位 |
| `wr_en` | 输入 | 1 | 写请求 |
| `wr_data` | 输入 | `DW` | 待写入数据 |
| `full` | 输出 | 1 | FIFO 已满 |
| `almost_full` | 输出 | 1 | 已用项数大于等于 `DEPTH - ALMOST` |
| `rd_en` | 输入 | 1 | 读请求 |
| `rd_data` | 输出 | `DW` | 寄存器化读出数据 |
| `empty` | 输出 | 1 | FIFO 已空 |
| `almost_empty` | 输出 | 1 | 已用项数小于等于 `ALMOST` |

`almost_empty` 在 FIFO 为空时也会有效，它表示水位状态，不代表存在可读数据。

## 4. 复位行为

当 `rst_n = 0` 时，无需等待时钟沿：

- `wptr` 清零。
- `rptr` 清零。
- `rd_data` 清零。
- 存储数组 `mem` 不逐项复位。

复位后 `used = wptr - rptr = 0`，所以 `empty = 1`、`full = 0`。

## 5. 写入约定

在 `rst_n = 1` 的时钟上升沿：

```verilog
if (wr_en && !full) begin
    // 接受本次写入
end
```

- 只有 `wr_en = 1` 且 `full = 0` 时才接受数据。
- 接受后，`wr_data` 写入当前写地址，`wptr` 在下一拍增加 1。
- 当 `full = 1` 时，即使 `wr_en = 1`，本次写请求也被忽略，不覆盖旧数据。

上游不能只看 `wr_en` 判断写入成功，必须同时检查 `full`。

## 6. 读取约定

在 `rst_n = 1` 的时钟上升沿：

```verilog
if (rd_en && !empty) begin
    // 接受本次读取
end
```

- 只有 `rd_en = 1` 且 `empty = 0` 时才接受读取。
- 接受后，当前读地址的数据通过非阻塞赋值更新到 `rd_data`，`rptr` 增加 1。
- `rd_data` 是寄存器输出，在该上升沿之后更新，不是组合读。
- 当 `empty = 1` 时，读请求被忽略，`rptr` 和 `rd_data` 保持原值。

下游只能在 `rd_en && !empty` 的时钟沿之后使用本次读出的 `rd_data`。

## 7. 空满计算

读写指针均为 `AW + 1` 位：低 `AW` 位用于寻址，额外最高位记录回绕。已用项数为：

```verilog
used = wptr - rptr;
full  = (used == DEPTH);
empty = (used == 0);
```

因为保留了折返位，指针多次回绕后仍能区分“指针相等但 FIFO 为空”和“写指针领先一整圈而 FIFO 为满”。

## 8. 同时读写

读写逻辑位于两个独立的时序过程。同一上升沿可以同时接受一个写入和一个读取，前提是各自满足 `!full` 与 `!empty`。满状态下的写入、空状态下的读取仍然被忽略。
